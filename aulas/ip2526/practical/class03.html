1) My first function submission

On this class all the exercises involve implementing a given function. Here are some notes:

  • The code you submit to Mooshak should therefore contain a function implementation as described.
  • Inside the function you should not print anything not explicitly asked on the problem statement.
  • Outside the function you can however print anything and for instance use the example function calls to test your code.
    (in fact we encourage you to actually always test with at least the given examples)
  • The file you submit to Mooshak should not have a name starting with a digit (e.g. ip023.py is ok but 023.py is not).
    (if you are curious why, it is because technically your file will be imported as a module)

To help you get started, here is some Python source code that serves as an example solution to the first problem from this class:

# [IP023] All in one
# Example Solution

# The function definition
def sum(a,b):
    return a+b

# Examples from problem statement
print( sum(1,2)   )
print( sum(-3,3)  )
print( sum(32,10) )
print( sum(7,8)   )
print( sum(4,-7)  )

# Some more examples
print("--------------------------")
print(sum(-1000,1000))
print(sum(40,3))

When executed, this python code will output the following, confirming it answers as expected:

3
0
42
15
-3
--------------------------
0
43
