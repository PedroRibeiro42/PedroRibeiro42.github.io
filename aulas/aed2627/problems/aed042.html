[AED042] Deep Nodes

In this problem you should only submit a binaryTree.h file with a self-containing definition of a class BTree<T>

Base Code

Use as a basis the class BTree<T> (see code | download code) which implements a generic binary tree that was explained in classes, with methods to read a tree from standard input, to write several node traversals, to count the number of nodes, to compute the height and to see if it contains a certain value.

The Problem

Add a new method int nodesLevel(int k) const to the class. The method does not change the tree, so it should be const (as seen in the lectures). The function should return the number of nodes at level k of depth. It is guaranteed that k will be a valid depth level, that is, the tree has at least one node on that depth. Submission

You should submit the file binaryTree.h with the method nodesLevel added to binaryTree<T> as requested (and without removing any of the other existing methods). You can however create additional methods, if you need them.

Mooshak will use the following code to link to your class, read the inputs, build the trees and call your method, printing its result.

#include <iostream>
#include <string>

#include "binaryTree.h"

// Read a tree of type t assuming "N" as the null value
// read n paths and call t.path() for each one of them
template <typename T>
void read() {
  BTree<T> t;
  t.read("N");

  int n;
  std::cin >> n;
  for (int i = 0; i<n; i++) {
    int k;
    std::cin >> k;
    std::cout << "t.nodesLevel(" << k << ") = " << t.nodesLevel(k) << std::endl;
  }
}

int main() {

  std::string type;
  std::cin >> type;
  if (type == "int") read<int>();
  else if (type == "string") read<std::string>();
  
  return 0;
}
